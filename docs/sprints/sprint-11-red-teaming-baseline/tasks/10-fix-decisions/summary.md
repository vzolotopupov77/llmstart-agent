## Принятые решения

| Решение | Причина |
|---|---|
| Побочный эффект — policy/конфиг, не промпт | F-06: отказ в `message` + запись в `leads.txt` |
| Пять пакетов вместо 25 заплаток | Совпадение механизма, не названия плагинов |
| `config_id` — заголовок `X-LLMStart-Eval-Key` / `EVAL_ACCESS_KEY` | Allowlist оставляет V2/V3; игнор ломает eval молча |
| Входной guard узкий (`HACKED:`, форматный медтест) | Классификатор тематики ломает воронку |
| F-05 и хвост F-09 — partial | Denylist «GPT» режет курсы; NLP third-party не отличит B2B |
| R-09/R-10/R-11 кодом в задаче 11 не усиливаются | Не воспроизвелись / ручной кейс R-11 после задачи 12 |
| Доказательство FIX-3/FIX-4: маркер + грейдер + pytest, не только JS `defaultTest` | Promptfoo не видит `leads.txt`; тон не имеет детерминированного ассерта |

Пользователь подтвердил 2026-08-15: (1) эффекты в коде, (2) заголовок для `config_id`, (3) defer и partial, (4) узкий входной guard, (5) матрица доказательства для прогона «после».

| Проблема | Как решили |

| Eval шлёт `config_id` в теле `POST /chat` | При флаге `true` без ключа — маркер; задача 11 добавляет заголовок в `evals/scripts/agent_task.py` |
