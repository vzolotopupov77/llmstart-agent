# ADR-0001 — Единое Agent Core, тонкие канальные адаптеры

> **Статус:** ✅ Accepted  
> **Дата:** 2026-05-01  
> **Область:** архитектура системы  
> **Supersedes:** —

---

## Контекст

Агент должен работать одновременно в двух каналах: веб-виджет (SSE) и Telegram. Логика воронки, RAG и инструменты одинаковы для обоих каналов.

## Решение

Вся бизнес-логика сосредоточена в одном компоненте **Agent Core** (`backend/`). Каналы (`web`, `telegram`) — тонкие адаптеры, которые только транслируют запрос в Core и форматируют ответ под свой протокол.

Core предоставляет единый `POST /chat` endpoint. Адаптеры не содержат логики воронки.

## Последствия

- `+` Воронка и RAG реализованы один раз, тестируются один раз.
- `+` Добавление нового канала не затрагивает Core.
- `−` Core становится центральной точкой отказа — требует отдельного мониторинга.
