# ADR-0003 — LLM-провайдер — OpenRouter

> **Статус:** ✅ Accepted  
> **Дата:** 2026-05-01  
> **Область:** LLM-интеграция  
> **Supersedes:** —

---

## Контекст

Нужен доступ к LLM-моделям. Прямые API (OpenAI, Anthropic) требуют отдельных ключей и SDK. Необходима возможность быстро переключать модели без изменения кода.

## Решение

LLM-провайдер — **OpenRouter** с OpenAI-совместимым API. Конфигурация через стандартные переменные `OPENAI_API_KEY` и `OPENAI_BASE_URL` — без кастомного SDK.

Модель выбирается через `OPENAI_MODEL` в `.env`, переключение без деплоя.

## Последствия

- `+` Единый ключ для доступа к сотням моделей.
- `+` OpenAI-совместимый клиент — стандартный инструментарий (LangChain, Langfuse callbacks).
- `−` Зависимость от доступности OpenRouter как посредника.
