# ADR-0002 — Инструменты агента — отдельный MCP-сервер

> **Статус:** ✅ Accepted  
> **Дата:** 2026-05-01  
> **Область:** архитектура инструментов  
> **Supersedes:** —

---

## Контекст

Агент использует инструменты: поиск по базе знаний, каталог продуктов, мок-оплата, запись лида. Нужен способ подключать инструменты без изменения Core.

## Решение

Все инструменты вынесены в отдельный **MCP-сервер** (`mcp_server/`), работающий по протоколу MCP. Core взаимодействует с ним как MCP-клиент через HTTP.

Инструменты регистрируются в MCP-сервере; Core не знает об их реализации — только о сигнатурах.

## Последствия

- `+` Инструменты можно разрабатывать, тестировать и деплоить независимо от Core.
- `+` Стандартный протокол MCP — потенциальная совместимость с другими клиентами.
- `−` Дополнительный сетевой hop; в dev-режиме handler'ы работают in-process.
