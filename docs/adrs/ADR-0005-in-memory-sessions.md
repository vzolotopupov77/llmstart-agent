# ADR-0005 — Память диалога in-memory, без БД на MVP

> **Статус:** ✅ Accepted  
> **Дата:** 2026-05-01  
> **Область:** управление сессиями  
> **Supersedes:** —  
> **Superseded by:** TBD (v1.0 — Postgres persistence)

---

## Контекст

Агенту нужна история диалога для поддержания контекста в пределах сессии. Постоянное хранение (Postgres) на MVP избыточно.

## Решение

История диалогов хранится **in-memory** в процессе Core: `dict[session_id → list[Message]]`. `session_id` передаётся клиентом в каждом запросе.

## Последствия

- `+` Нулевая сложность: нет миграций, нет ORM, нет зависимостей.
- `+` Достаточно для demo и курса.
- `−` Перезапуск Core сбрасывает все сессии.
- `−` Не масштабируется на несколько экземпляров Core.
