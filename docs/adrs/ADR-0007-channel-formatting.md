# ADR-0007 — Форматирование ответа в Core по параметру channel

> **Статус:** ✅ Accepted  
> **Дата:** 2026-06-05  
> **Область:** форматирование ответов  
> **Supersedes:** —

---

## Контекст

Веб-виджет ожидает Markdown/HTML, Telegram — HTML-разметку Telegram Bot API (`<b>`, `<i>`, ссылки). Форматирование нельзя делать на стороне канального адаптера, не зная структуры ответа агента.

## Решение

Core принимает параметр `channel` в теле запроса (`"web"` | `"telegram"`). Финальный текст форматируется внутри Core перед отдачей в поток/JSON.

Адаптеры передают `channel` и не трогают текст ответа.

## Последствия

- `+` Единая точка форматирования — изменение шаблона не требует правок в адаптерах.
- `+` Легко добавить новый канал (`"voice"`, `"email"`) без дублирования логики.
- `−` Core знает о существующих каналах — потенциальный рост ветвлений.
