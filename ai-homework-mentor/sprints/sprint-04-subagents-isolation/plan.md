## Цель спринта

Ввести Reviewer-субагентов с изолированным контекстом и через verbose-режим показать контраст с Sprint 03: субагент стартует чистым, возвращает только саммари, контекст оркестратора растёт на 200 токенов вместо 4 500.

**Боль, которую закрывает:** Sprint 03 наглядно показал раздувание контекста при проверке всего в одном агенте. Теперь вводим изоляцию: каждый аспект рубрики проверяет отдельный субагент в чистом контексте.

**Deep-agent механизм:** spawning субагентов + изоляция контекста. Оркестратор формирует узкие брифы и делегирует; субагент видит только свой бриф + нужные файлы; возвращает ReviewNote через файл — не через историю.

## 🎭 Образовательная драматургия

Это второй из двух «образовательных» спринтов. Задача — показать **решение той же задачи с изоляцией**, чтобы пользователь увидел контраст своими глазами.

Verbose-режим теперь показывает для каждого аспекта:
- панель «запущен субагент»: 0 токенов истории, бриф X токенов
- панель «субагент завершён»: его контекст Y токенов (изолирован, не передан оркестратору)
- строка роста оркестратора: `+200 токенов` вместо прежних `+4 500`
- рядом: `↑ В Sprint 03 без изоляции: +4 500 токенов`

После этого спринта пользователь понимает механику изоляции интуитивно — не из текста документации, а из наблюдения за реальными числами.
